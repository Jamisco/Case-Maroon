# Case Maroon

A 2D multiplayer war strategy game built in Unity, with a custom frontend and backend.

## Structure

- `Case Maroon_Unity/`: Unity project (C#)
- `Case Maroon_Frontend/`: Frontend UI (React + Vite)
- `Case Maroon_Backend/`: Game server (Express.js + Node.js)

## Build targets

- PC
- WebGL
